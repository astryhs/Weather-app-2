# 🌤️ Прогноз погоды

Веб-приложение для просмотра актуального прогноза погоды с возможностью выбора города, смены цветовой темы и сохранением настроек в браузере.

## 📋 Функционал

- ✅ **Прогноз погоды** – текущая температура, влажность, скорость ветра
- ✅ **Выбор города** – ручной ввод и выбор из списка
- ✅ **Смена темы** – светлая / тёмная тема оформления
- ✅ **LocalStorage** – сохраняется тема при перезагрузке страницы
- ✅ **Адаптивный дизайн** – корректно отображается на ПК, планшетах и смартфонах

## 🛠️ Используемые технологии

- **HTML5** – структура страницы
- **CSS3** – стилизация, адаптивность, анимации
- **JavaScript (ES6+)** – логика приложения, работа с DOM, API, LocalStorage
- **OpenWeatherMap API** – получение данных о погоде
